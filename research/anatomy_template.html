Selectivity: effect on solid colours vs on general prompts (layers 21–41)

How much each fix changes the layers' outputs, as a share of a full revert's change. Up = more change on the activations SFT produces while drawing solid colours (where the stripes are). Right = more change on ordinary prompts (drift). The grey diagonal is a plain scaled revert, which can't tell the two apart; the further above it a fix sits, the more selective it is. Changing a LoRA's strength slides its point along the straight line from the origin (Kijai @ −0.5 is half way to Kijai @ −1; nynxz @1.5 is 1.5× further out than @1.0).

How to read this

Weight size (top chart) shows where a fix acts, not how much it matters: a large change on a direction the model never uses does nothing. The reverts are flat 100% blocks. The Gram solves cover 21–41 but keep only part of each layer's difference. Kijai's LoRA is a rank-512 approximation, so it is partial everywhere and also touches layers 3–4.

Output effect (charts 2–3) weighs the weight change by how often each input direction actually occurs: tr(D·G·Dᵀ), with G the recorded activation statistics. That is the change in each layer's output on real activations, before the later layers react to it. The output energies of the four matrix types are summed, so the large MLP matrices dominate. Only layers 21–41 have recorded activations, so Kijai's layers 3–4 are not counted in charts 2–3.

In-sample caveat: DeBand Strong (and the μ-protected solves) were fitted to keep the general-prompt detail recording (the same row-centred statistics the "general prompts" axis uses) unchanged, so their low drift on that axis is partly by construction. nynxz's Destripe never saw these recordings, so its position is an out-of-sample measurement. The rendered results (compare page) are the fair test: there Strong drifts more than nynxz (faces 0.83 vs 0.94).

Rendered results in the tooltips (solid HF dB vs SFT, ArcFace vs SFT) are single-seed means from the image comparison, a sanity check on whether the selectivity shows up in pixels.
